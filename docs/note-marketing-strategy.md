# note マーケティング戦略メモ（2026-08 改訂版）

有料note 1件購入後にフォロー・スキが止まった状況を受けて、原因分析と競合調査をもとに戦略を再設計する。

---

## 1. なぜ「1購入のあと」に止まったのか — 原因分析

### 原因① 購入者はフォロワーにならない
有料記事の購入者は、X や検索から「その記事の情報」だけを目当てに来る一見さんが多い。
購入がゴールになっており、**「この人を追い続けたい」と思わせる無料の入口（連載・シリーズ・人柄が見える記事）がないとフォローには繋がらない**。
購入 → フォローの転換には「次も読みたい」という期待の設計が必要。

### 原因② 流入がスパイク型（一度きり）
発売告知の瞬間だけ露出が増え、その後の供給が止まると note のおすすめ・新着面から消える。
note の露出はスキ率と更新頻度に大きく依存するため、**投稿が止まる＝発見されなくなる＝スキもフォローも止まる**という構造。

### 原因③ 無料記事による信頼の蓄積が足りない
競合の定石は「無料記事を10本以上出してから有料化」。無料で価値を証明する前に有料を売ると、
プロフィールを見に来た人が「フォローする理由」を見つけられずに離脱する。

### 原因④ 交流（スキ回り）不足
note は初期フェーズでは SNS 的な相互作用がほぼすべて。自分からスキ・フォロー・コメントをしないと存在に気付かれない。
「スキがもらえない一番の理由は、存在に気付かれていないから」が定説。

### 原因⑤ 「役に立つ」だけではスキは付きにくい
スキは「感動した」「共感した」に付きやすい。技術ノウハウ系は特に、
**独自の体験談・失敗談を混ぜないと読後にアクションが起きない**。

## 2. 市場データからの示唆（note公式 約30万件の有料記事分析）

- **実用系ノウハウの平均価格は 1,842円**、読み物系は 983円（約1.9倍の差）。実用系は高単価が通る。
- 成長ジャンルは **「AI活用」「SNS運用」「育児」** — AI活用はまさに追い風の領域。
- 売れる鍵はジャンルより **「その人ならではの独自体験」**。
- 有料記事市場全体は前年比 +26.8%、メンバーシップは +80% 超で拡大中。

→ 「Claude エージェントで実際にアプリを作った過程」という一次体験を持っているのは強み。
一般論の AI 解説ではなく **開発の実録 + 再現手順** に寄せるべき。

## 3. 競合（売れているAI系noteアカウント）の勝ちパターン

調査から抽出した、再現可能な共通戦術：

| # | 勝ちパターン | 具体策 |
|---|---|---|
| 1 | 無料→有料のファネル | 無料記事10本以上で信頼を作ってから有料。最初の有料は **300円のテスト価格** で反応を見る |
| 2 | 「そのまま使える素材」を付ける | プロンプト集・テンプレート・チェックリスト同梱。有料部分は **3,000〜5,000字以上** |
| 3 | X との毎日連携 | X で毎日1回ノウハウを小出し → note へ誘導。SNS→note→サイト(CV) の導線 |
| 4 | タイトルの型 | 数字 + ベネフィット + 最新性（例:「【2026年最新】〜で月3万円」）。検索される言葉を入れる |
| 5 | 冒頭3行で掴む | 結論 or 読者の悩みを最初に置く。既存記事もタイトルと冒頭だけリライト可能 |
| 6 | マガジン化・シリーズ化 | 週1更新の有料マガジン（月額500円目安）でストック収益化。フォローする理由を作る |
| 7 | 実績の透明化 | 収益・PV・失敗を公開する「実録記事」はスキと共感を集めやすい |
| 8 | スキ回り・交流 | 同ジャンルの記事に毎日スキ・コメント。初期の露出はほぼこれで決まる |

## 4. 戦略変更プラン（4週間）

### Week 1: 土台の立て直し
- [ ] プロフィール整備: 「誰に・何を・なぜ自分が」を明記し、ポートフォリオサイト（https://usagi7777777.github.io/ai-portfolio/）へのリンクを設置
- [ ] 既存有料記事の **無料部分・タイトル・冒頭3行をリライト**（数字とベネフィットを入れる）
- [ ] 無料記事を3本公開（テーマ案: Claude Code で○○を作った実録／つまずいた失敗談／使ったプロンプト公開）
- [ ] 毎日10件、同ジャンル（AI活用・個人開発）の記事にスキ + 週3コメント

### Week 2–3: 供給と導線の確立
- [ ] 無料記事 週2本ペース（「AI開発実録」シリーズとしてマガジンにまとめる）
- [ ] X で毎日1ポスト（制作過程のスクショ + 学び1つ + note リンク）
- [ ] ポートフォリオサイトのフッターリンク（現在プレースホルダ）に note / X の実URLを設定し相互導線を作る

### Week 4: 有料の再設計
- [ ] 次の有料記事は **実用系**: 「Claude エージェントで◯◯を作る完全手順（プロンプト全文 + テンプレ付き）」
- [ ] 価格はまず 300〜500円でテスト → 反応を見て 980〜1,800円へ段階値上げ
- [ ] 購入者特典に「シリーズの次回作の割引 or マガジン案内」を入れ、購入→フォロー転換を設計

|---|---|---|
| 無料記事本数 | — | +8本 |
| フォロワー | — | +30〜50 |
| 平均スキ/記事 | — | 10+ |

## 5. 要点まとめ

1. **止まった原因は「供給停止 + 無料の入口不足 + 交流不足」の複合**。有料記事単体の問題ではない。
2. **AI活用は note 公式データでも成長ジャンル**。撤退ではなく、実録・実用系への寄せ替えが正解。
3. 真似るべきは「無料10本 → X毎日導線 → テンプレ付き実用系有料 → マガジン化」の王道ファネル。
